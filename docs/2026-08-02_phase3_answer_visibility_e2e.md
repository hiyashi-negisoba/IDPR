## 일반화 규칙

1. 검토 후보와 답안 노출 범위를 분리한다. Call 2와 Scallop의 평가·관계는 삭제하지 않고
   Call 3에서 `full`, `compact`, `hidden`으로 표시 강도만 정한다.
2. 긍정적 구성요건 지지가 없는 후보는 숨긴다.
3. 명시적으로 반증된 구성요건 쟁점 수가 지지된 쟁점 수 이상이면 숨긴다.
4. 미확정 후보는 사실에 연결된 서로 다른 평가 쟁점이 두 개 이상일 때만 compact로
   남긴다. 이 조건은 확정된 단순범에는 적용하지 않는다.
5. 결과적 가중범·결합범은 검수된 선행 기본범 중 하나가 gap 없는 성립 신호를 가져야
   독립 죄명으로 노출한다. 현재 표는 상해치사, 강간등 상해·치상, 강도상해·치상,
   강도살인·치사를 다룬다.
6. compact는 full IRAC와 분리된 `보충적 검토`에 모으고, `satisfied`된 사실 포섭만 짧게
   보여준다.
7. 조문 제목과 쟁점 제목은 모델이 정하지 않는다. JSON Schema에서 입력 제목을 `const`로
   결박하고, 호스트가 다시 덮어쓴 뒤 검증한다. 숨긴 조문 진단은 모델 입력에서 제거하고
   저장 산출물에만 남긴다.

## 남은 문제와 작업 경계

이번 변경은 답안 가시성과 identity 계약을 바로잡았으며 검색 정책과 Scallop 원관계는
변경하지 않았다. 다음 문제는 별도 upstream/symbolic 작업이다.

- KCL 제297조 본문은 간음 미완료와 중지미수를 서술하지만 Scallop의
  `final_offense` 때문에 호스트 결론은 여전히 “성립”이다. Call 2가 실행행위와 기수를
  한 element issue에 합쳐 판정하고, 현재 Scallop이 element 하나의 지지만으로 죄를
  성립시키는 문제다.
- 제319조와 제301조는 필요한 사실·법리 일부가 unknown이라 compact 미확정으로 남는다.
- 사용자 문항의 제355조는 불법영득의사만 충족되고 위탁관계·보관자 지위가 unknown이라
  compact 미확정이다. 죄수관계도 upstream 관계 판정이 충분하지 않다.
- 검색 top-10은 여전히 실험 후보일 뿐 기본값 top-18을 변경하지 않았다.
- 나머지 59문항은 이번 설계·판단에 사용하지 않았다. 전체 데이터셋 평가는 별도 최종
  평가 시점에 수행한다.

따라서 이번 작업은 “후보를 넓게 검토하되, 독립 답안에는 일반 규칙으로 물적으로 근거된
쟁점만 노출한다”는 배선을 마련하고 두 실제 E2E 출력에서 개선을 확인한 지점에서 종료한다.
