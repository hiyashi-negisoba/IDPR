# 강간 RuleIR 일괄 법률검수 게이트 01

대상은 현재 카드 자산의 제297조 56장 전부다. 카드별 판정은 다음 세 문서에 있으며 고유
카드 56/56, 누락 0, 중복 0이다.

- `p2/rape_proposal_01.md`: 기본 구조·객체·배우자·증거 18장
- `p2/rape_proposal_02.md`: 폭행협박·간음·동의·고의·미수경계 23장
- `p2/rape_proposal_03.md`: 죄수·가중유형·외부 연결 15장

승인 전에는 승인 원장, RuleIR 또는 SCL에 편입하지 않는다.

## G-R01 — 카드별 판정

56장 표의 `decision / role / component / join / track / refers_to`를 일괄 승인하는가?

## G-R02 — base 단일 track과 역할 tuple

다음을 승인하는가?

- 컴파일 track: `base` — 제297조 강간 기수
- 역할 tuple: `rape_case_roles(case_id, defendant_id, victim_id)`
- 제300조 미수·중지미수는 중복 track을 만들지 않고 `sexual_offense_attempt` unit으로 연결
- 간접정범 #2는 intermediary 역할을 갖춘 공유 총칙 module 전까지 `context_only`

## G-R03 — 질성교와 성별 판단

다음을 실행요건으로 승인하는가?

- #13: 단독정범의 질성교 구조상 행위주체와 객체는 서로 다른 성
- #14: 성별은 성염색체만이 아니라 성귀속감, 사회적·규범적 성 및 일반인의 평가를 종합
- #31: 남성 성기의 여성 성기 삽입·결합 순간 기수, 완전삽입·사정 불필요
- #26: 구강·항문성교 등은 제297조를 차단하고, 현재 미등록 `quasi_rape`로
  `predicate_ir_missing`

## G-R04 — 폭행협박·동의·고의 경계

다음을 승인하는가?

- 폭행·협박은 항거를 불가능하거나 현저히 곤란하게 할 정도라는 최협의 기준
- #15는 타인이 만든 강제상태를 단순 이용한 경우만 강간을 차단하고 준강간으로 이동
- #37 피해자 본인의 유효한 성관계 동의는 구성요건 해당성을 차단
- #40 동의가 있다고 오인한 경우 강간 고의를 차단
- 피해자의 연락·호감만으로는 동의가 아니며(#36), 사전 동의도 번복할 수 있음(#38)

## G-R05 — 증거·미수·죄수의 분리

다음을 승인하는가?

- 성인지 감수성·피해자 진술·무고 증명 #19·#20·#21·#24·#48은 `context_only`
- 미수 착수·자의적 중지 #29·#30·#32는 `sexual_offense_attempt`의 `post_outcome`
- 죄수·특별법·결과가중 #4·#5·#33·#34·#41~#47·#49~#56은 `post_outcome`
- 등록된 재산죄·P2 unit 참조만 resolved로 두고, 나머지는 가짜 fallback 없이
  `predicate_ir_missing`
