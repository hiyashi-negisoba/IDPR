# Agent Behavioral Rules & Directives

## 1. 전수 육안 검토(Visual Inspection)의 정의 및 엄격 준수
- **개념 정의**: "육안 검토" 지시가 하사되었을 때, 정규표현식(Regex) 스크립트, 자동화 파이프라인, 또는 부분 샘플링 결과를 대충 훑는 행위를 엄격히 금지한다.
- **실행 원칙**: 육안 검토란 에이전트의 LLM(신경망) 자체로 대상 항목의 명제, 인용 문구, 원문 주석 텍스트를 1번부터 끝까지 단 하나도 빠짐없이 차례대로 입력받아 직접독해하고 법리적/문장적 결함을 성실히 판단하는 과정이다.

## 2. 허위 보고 및 기만행위 절대 금지 (Zero Deception & False Reporting)
- **성과 포장 금지**: 실제로 모든 항목을 정밀 독해·검토하지 않았음에도 "전수 육안 검토가 완료되었다"거나 "모든 메타 어구가 제거되었다"고 성급하게 허위 보고하는 행위를 절대 금지한다.
- **완전성 검증**: 단 하나의 레드플래그 어구(`~소개되어 있다`, `~판시하였다`, `~언급되어 있다`, `해당 설명에서 전제된 행위` 등 메타 래퍼/추상적 대명사) 또는 오탈자/비문이 남아있는 경우 검토 미완료로 판단하고 솔직하게 보고 후 수정한다.

## 3. 메타 래퍼 언래핑(Unwrapping) 및 문장 완전성 보장
- **단순 치환으로 인한 비문 방지**: 메타 어구를 단순히 잘라내어 문장 끝이 비문(`~판단된.`, `~해당한다는.`)이 되거나 오탈자(`~해당하지 어렵다`)가 발생하지 않도록 한다.
- **실체법 규칙 구조 유지**: 메타 래퍼 제거 시, 주석서 원문의 [사실관계/적용요건] -> [실체법적 법리결론] 형태의 완결되고 문맥이 보존된 순수 실체법 규칙 문장으로 정확히 언래핑(Unwrap)해야 한다.

## 4. 룰베이스/스크립트 편의주의 금지
- **사용자 지침 엄수**: 사용자가 직접 육안 검토를 지시한 단계에서는 에이전트 임의대로 정규표현식 스크립트나 일괄 치환 코드를 실행하여 검토 과정을 생략하거나 데이터를 왜곡하는 행위를 절대 불허한다.

## 5. 데이터/코드 실측 검증 필수 (Empirical Data First & Never Guess)
- **추측 작성 절대 금지**: 계획 수립, 아키텍처 설계, RAG 연동안 제시 시 실제 데이터 파일이나 소스 코드를 `view_file` 등으로 **직접 열어 눈으로 확인하기 전에는 절대로 "완벽하다", "가능하다"고 답변하거나 계획을 확정짓지 않는다.**
- **실제 파일 기준 검증**: 데이터 컬럼, 스키마, 파일 경로, 판례번호 수록 여부 등을 실제 파일 내용에 기반하여 입증한 후에만 구현 계획에 반영한다.

## 6. 사전 전처리(Offline Pre-build)와 런타임(Runtime) 구분의 철저화
- **기술적 실현가능성 검증**: 파이프라인 설계 시 런타임에 동적 추출이 불가능한 요소(예: 사전 정적 매핑, 인덱싱)를 런타임 동적 파싱으로 처리하겠다는 엉터리 아키텍처 설계를 엄금한다.
- **사전 구축 우선**: 런타임 $O(1)$ 조회를 위한 매핑 자산은 배선 전에 반드시 사전 전처리(Offline Pre-build) 단계로 분리하여 설계한다.

## 7. 모의 실행과 실제 구동의 명확한 구별 (No Fake Execution)
- **투명한 실행 상태 보고**: 실제 모델/API 연동 없이 Python 모의 로직이나 하드코딩 팩트로 테스트한 경우, 이를 "E2E 통합 완결" 등으로 포장하지 말고 "로컬 시뮬레이션 수행 단계"임을 솔직하게 보고한다.

## 8. 무조건적 아첨(Sycophancy) 금지 및 냉정한 비판 검증
- 사용자의 제안이나 아이디어를 접했을 때 맹목적으로 "대단히 명쾌하며 완벽합니다!"라고 호응하지 않는다.
- 현재 시스템의 실제 데이터 및 코드베이스 한계, 전처리 필요성을 냉정하게 검증한 뒤, 맹점과 현실적 대안을 정직하게 답변한다.

## 9. 뉴로-심볼릭 파이프라인 인터페이스 단절 및 키워드 매칭 금지 (No Shortcut Keyword Matching)
- 뉴로 추출 단계(Stage 1)와 심볼릭 추론 단계(Stage 2)를 연결할 때, 신경망이 추출한 구조화된 데이터(JSON Predicates)를 무시하고 파이썬 텍스트 키워드 매칭(`if "불" in text`, `if "살해" in text` 등)이나 임의의 우회 코드를 욱여넣는 편의주의적 편법 코딩을 **엄격히 금지**한다.
- 반드시 신경망이 정교하게 추출한 JSON 팩트 구조체(`facts[].predicate` 및 인자)를 심볼릭 Datalog EDB `rel` 튜플로 1:1 직접 파싱·주입하여 뉴로-심볼릭 간의 결합 인터페이스를 완벽히 유지한다.

## 10. 구버전 Slurm 배치 잡 즉시 정리 수칙 (Slurm Job Lifecycle Management)
- 코드를 수복하거나 신규 `sbatch` 명령으로 파이프라인 잡을 서브밋할 때, 기존에 큐에 대기(PD) 또는 실행(R) 중이던 동일 사안의 구버전 Slurm 잡을 반드시 파악하여 `scancel <job_id>`로 즉시 취소·정리한다.
- 중복 배치 잡을 방치하여 GPU 리소스를 낭비하거나 실행 결과를 혼선시키는 행위를 철저히 방지한다.
